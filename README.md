# HWPL CRM prototype

This is a clickable prototype of the Healthware (HWPL) CRM, published so the team can review the flows.

- **Start here:** https://sivapolu.github.io/hwpl-crm-prototype/
- **Web app:** `web.html`. It shows the desktop screens, with role buttons for Sales Exec, RM, NSM, Dealer, Admin and Clinical Apps.
- **Mobile app:** `mobile.html`. It shows the field app on Android (360 px wide) and iPhone (390 px wide) side by side.

All data is sample data. Nothing is saved or sent, and reloading a page resets it.
